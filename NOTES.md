## Three Things I Would Improve

### 1. Input Validation
I would add better input validation to prevent users from submitting empty task titles. This would help maintain accurate and useful task records.

### 2. Error Handling
I would improve error handling. For example, if the server is unavailable or a request fails, the application should display a helpful message instead of failing silently.

### 3. Responsive Design
I would improve the responsive design so the application works properly on mobile phones, tablets, and desktop screens. This would make it easier for users to manage their tasks on different devices.
